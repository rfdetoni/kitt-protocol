# KAP/2 — compact model-facing actions

KAP/2 is a strictly bounded, TOON-inspired textual format generated by the LLM. The trusted host alone translates actions into tool calls and enforces the actual declared tool schema, approvals, execution policy and completion verification. The internal JSON transport and IPC Envelope v1 are independent of this syntax.

## Frames

```text
K2 T kitt_runtime
operation: repo.read
arguments:
  path: README.md
K2/END
```

```text
K2 F
Completed with verified evidence.
K2/END
```

`K2 T <declared tool>` requests one tool; `K2 F` is final; `K2 W` requests workspace context; `K2 Q` requests tool catalog. Exactly one action per response. A standalone `K2/END` terminates the frame; it is recognized only outside a literal block.

The reverse-proxy may support `K2 T repo.read` only if the host-provided schema for exactly one declared tool exposes `repo.read` as an explicit allowed `operation` enum value and has an `arguments` schema. The host then reconstructs `{operation: "repo.read", arguments: ...}` and validates it against the full tool schema. No implicit alias registration or authority expansion.

## Fields

Two spaces per nested object level. Tabs are forbidden. Keys match `[A-Za-z_][A-Za-z0-9_]*`; prototype/constructor keys, duplicate keys, and conflicting fields are rejected.

```text
K2 F
summary: Complete
meta:
  revision: 2
  verified: true
files[2]:
  - src/app.ts
  - src/test.ts
tasks[2]{id,status}:
  T01,done
  T02,pending
K2/END
```

Unquoted scalars are strings except for `true`, `false`, `null`, canonical safe decimal integers and finite decimal values. JSON double-quoted strings represent ambiguous strings (for example `"001"` or `"true"`). Tabular cells use CSV quoting with doubled quotes, not JSON escaping; headers are unique scalar field names and counts are exact. Arrays are bounded by 1024 rows. List entries use `- value` inside a declared `key[count]:` array.

## Literal source

```text
K2 T repo.write_file
path: src/app.ts
content<<CODE
export const text = "hello";
K2/END
CODE
K2/END
```

The marker must be an uppercase `[A-Z_][A-Z0-9_]{0,24}` tag, absent as a standalone line from the payload itself. Within the block content remains literal (including `K2/END`), without escaping or rewriting quotes and indentation. Unterminated/ambiguous blocks are rejected, not guessed.

## Limits and compatibility

64 KiB UTF-8/frame, at most 3000 lines, nesting at most 20, arrays at most 1024 rows, one envelope only. The proxy validates tool declarations and schemas after parsing; the Python SDK exposes a structured-final decoder. Invalid/incomplete syntax is not executed or automatically coerced into a different action. No model-generated batch execution or references to privileged host resources are authorized by this format.

The KAP/1 decoder remains available for stored examples during migration; the model prompt uses KAP/2. Changes to the canonical grammar must be propagated to both TypeScript copies and verified by parity checks.

## Future host features

Batch read-only execution, positional arguments, revision-aware code patches and evidence references need explicit host-side identities, capability negotiation, lease ownership and idempotency checks before they are added as model actions.
